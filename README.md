# ByteBridge Digital Website

## Project description
ByteBridge Digital is a fictional technology company website created for an HTML, CSS and JavaScript practical project. It introduces the company, explains its services and provides a contact form demonstration.

## Technologies used
- HTML5: page structure and content.
- CSS3: colours, spacing, layout and responsive design.
- CSS Flexbox: navigation bar, buttons and footer alignment.
- CSS Grid: About, Services and Contact layouts.
- JavaScript: mobile navigation, automatic footer year and contact form validation.

## Project files
- `index.html` — website content and structure.
- `style.css` — visual design and responsive layouts.
- `script.js` — interactive features and form validation.

## How to run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser. You can also use the VS Code Live Server extension.

## Important note about the contact form
The form validates the visitor's entries in the browser. It does not send, save or deliver messages because no backend or form submission service is connected.

## Project type
Student practical project / demonstration website.
